# Statussymbole – Codeabgleich

Stand: 2026-11-15. Entwürfe, noch keine eingebauten UI-Assets.

| Stab | Benötigte Statusanzeige |
| --- | --- |
| Feuerstab | Brennen |
| Eisstab | Verlangsamt (Kälte), kein vollständiges Einfrieren |
| Giftstab | Vergiftet |
| Mondstab | Kein anhaltender Zielstatus |
| Sternstab | Kein anhaltender Zielstatus |
| Blitzstab | Betäubt |
| Sanduhrstab | Zeitverlangsamung |
| Meteorstab | Brennen, gleiches Symbol wie Feuerstab |
| Sonnenstab | Geblendet und aufgedeckt, getrennte Anzeigen |
| Seelenrichterstab | Seelensiegel 1/3, 2/3, 3/3; dritte Stufe kündigt Hinrichtung an |
| Gravitationsstab | Optional: Sog während tatsächlicher Bewegung; kein anhaltender Debuff-Timer |
| Teleportationsstab | Kein anhaltender Zielstatus |
| Schutzstab | Projektilschutz, keine allgemeine Unverwundbarkeit und keine Rückspiegelung |
| Erdbrecherstab | Kein zusätzlicher anhaltender Zielstatus |
| Runenmauerstab | Mauer-Lebensdauer als Fähigkeitsanzeige, kein Zielstatus |
| Schattenstab | Verdunkelt; im Feld erneuert, danach Restdauer |
| Uhrwerkstab | Wächter-Lebensdauer als Fähigkeitsanzeige, kein Zielstatus |

Die zwölf Symbolfelder zeigen neun gewöhnliche Zustände und drei Stufen des Seelensiegels. Farbton und Silhouette unterscheiden Lichtblendung von Schattenverdunkelung. Abklingzeiten und beschworene Objekte gehören separat zur Fähigkeitsanzeige.
