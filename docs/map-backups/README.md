# Kartenstand vor dem Leeren

`worldmap-2026-11-20-before-clear.json` sichert die vollständige Projektkarte vor dem ausdrücklich gewünschten Leeren: 1.095 Objekte, 112 Wege einschließlich der zwei Brücken, 26 Hindernisstriche, vier Barrieren und alle Boden-/Biommalereien.

Der Stand stammt aus Commit `42c38496caedf51569f8b3b75dbf0470519b2f66` und kann über „Öffnen“ im Editor als JSON wieder geladen werden. Die Modelldateien und Editor-Kataloge bleiben im Projekt erhalten.

Die Projektkarte wurde vollständig von gesetzten Inhalten geleert. Automatische Bodendekoration und lokale Übungsgegner sind für diese Karte ausgeschaltet. Frühere Browserentwürfe werden nicht ferngesteuert überschrieben; im Startdialog „Aktuelle Projektkarte öffnen“ wählen.

Die aktuelle leere Grundlage wurde anschließend auf drei Biome (Schnee, Wald/Wiese, Wüste) umgestellt, um 20 % in beiden Achsen vergrößert und an den Küsten abgerundet. Sie verwendet schwebende Felskanten über einer Nebeltiefe. Der gesicherte alte Stand bleibt unverändert.
