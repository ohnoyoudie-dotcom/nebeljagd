# Holzkarren: Bildvorlage für Tripo

`cart-reference.png` zeigt einen leeren mittelalterlichen Handkarren mit
zwei Rädern, einer gemeinsamen Achse und zwei Zugholmen. Stilreferenzen sind
der aktuelle Spieleravatar, die überarbeitete Truhe und das Holzfass;
maßgebend bleiben die [gemeinsamen Stilregeln](../../../docs/art-style.md).

Das Bild einzeln in Tripo zur 3D-Erzeugung verwenden und das Ergebnis als GLB
mit eingebetteten Texturen exportieren. Der Eingangspfad ist
`assets/inbox/holzkarren/nebeljagd_holzkarren_v1.glb`.

Grobe Größenreferenz: Ladefläche etwa 1,3 × 0,95 m, Raddurchmesser 0,75 m,
Gesamtlänge mit Holmen ungefähr 2,4 m. Beim Import Maßstab neben dem Avatar,
Räder/Achse, freie Zwischenräume und Kollisionen prüfen. Für eine spätere
Bewegung müssen Räder getrennt drehbar sein; die Bildvorlage garantiert
keine getrennten Modellteile.

Dies ist ausschließlich eine 2D-Bildvorlage. Ein GLB oder ein neues
Kartenobjekt wird dadurch noch nicht erstellt. `provenance.json` dokumentiert
Prompt, Stilreferenzen und Bild-Hashes.
