# Truhe: Bildvorlage für Tripo

Die aktuelle Vorlage ist `chest-reference.png`. Sie wurde anhand des aktuellen
Spieleravatars überarbeitet. `chest-reference-v1.png` bleibt als vorheriger
Entwurf erhalten; sie enthält deutlich mehr fotografische Oberflächendetails.

Gemeinsamer Stil: [Projektregeln](../../../docs/art-style.md).

Das aktuelle Bild einzeln in Tripo zur 3D-Erzeugung verwenden und das Ergebnis
als GLB mit Texturen exportieren. Danach werden Deckel, Innenraum, Drehpunkt,
Maßstab und Materialien in Blender geprüft und für das Spiel vorbereitet.
Weitere Hinweise stehen in `tripo-hinweise.txt`.

Dies ist ausschließlich eine Bildvorlage. Ein neues Truhenmodell oder eine
Änderung der vorhandenen Spieltruhen wurde damit noch nicht erzeugt. Die
Prompts und Bild-Hashes stehen in `provenance.json`.
