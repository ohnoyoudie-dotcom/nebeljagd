# Felsen: Eingangsablage

Die unveränderten Tripo-Exporte mit Texturen hier ablegen, beispielsweise als
`nebeljagd_fels_01.glb`, `nebeljagd_fels_02.glb` und `nebeljagd_fels_03.glb`.
Dieser Hinweis erstellt noch keine Modelle.

Die getrennten Bildvorlagen liegen unter `assets/concepts/rocks/`.
Vor dem Einbau werden Geometrie, Maßstab, Materialien, Kollisionen und
Sichtblockaden geprüft. Die vorhandenen Spiel-Felsen bleiben bis zum
gezielten Einbau der neuen Modelle erhalten.
