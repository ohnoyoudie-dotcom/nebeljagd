# Truhe: Eingangsablage

Neue Tripo-Exporte mit Texturen können hier abgelegt werden, beispielsweise als
`nebeljagd_truhe_v1.glb`.

Das bereits gelieferte Original liegt aktuell eine Ebene darüber:
`assets/inbox/treasure chest 3d model.glb`. Die Datei wurde über den Branch
`work` übernommen und bleibt unverändert. Erste Prüfung der GLB-Metadaten:
65.164.384 Bytes, 1.947.170 Dreiecke, ein Mesh, ein Material, keine Animationen.
Vor dem Einbau sind eine Geometrieoptimierung und die Prüfung von Deckel und
Innenraum erforderlich. Die Datei ist noch nicht in Spiel oder Editor eingebaut.

Aktuelle Bildvorlage: `assets/concepts/chest/chest-reference.png`.
Anschließend werden Deckel, Innenraum, Scharnier, Maßstab und Materialien
geprüft und für die vorhandene Öffnungsbewegung vorbereitet.
