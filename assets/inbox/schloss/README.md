# Eingang: Schloss

Das **kleine Schloss ist bereits vorhanden**:
**assets/inbox/castle interior 3d model.glb** bleibt als Original erhalten.
Seine aufbereitete Spielversion liegt unter **assets/imported/tripo-castle/**.
Im Editor heißt sie **„Kleines Schloss · Tripo“**.

Dieser Unterordner kann für weitere Schloss-Exporte verwendet werden, etwa das
spätere große Gartenschloss. Unterschiedliche Modelle mit eigenen Namen speichern.

Hier den unveränderten Tripo-Export als `nebeljagd_schloss_v1.glb` mit
eingebetteten Texturen ablegen und auf Branch `work` committen/pushen.

Bildvorlage und Maßvorgaben: [Schloss-Konzept](../../concepts/castle/README.md).
Ein kopiertes Modell erscheint noch nicht automatisch im Spiel oder Editor.
Vorher werden Geometrie, Durchgänge, Maßstab, Kollisionen, Sichtblocker und
Browserleistung geprüft. Bei diesem großen Gebäude ist eine Aufteilung in
Architektur und separate Einrichtung vorgesehen.
