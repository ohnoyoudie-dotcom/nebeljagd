# Nebeljagd ranger · original character source

`ranger.blend` is the editable Blender 4.3.2 source. `ranger.glb` is the browser runtime asset, generated by `scripts/build-character.py`. The generator constructs all geometry, vertex colours, fittings, clothing, skeleton and motion locally. No external model, texture, original game asset, motion capture or provider service was used.

The ranger has adult stylised proportions, a fitted tunic, split coat, leather bracers/boots, open hood, cloak, pack and small brass fittings. The roughly 2.05 metre character faces +Z in glTF coordinates and has 18 joints. Its body is a skinned mesh with three reusable material primitives. The neutral `Idle` and alternating `Walk` clips are authored with bone keyframes, rather than translating an unanimated model. Locomotion playback is adjusted to movement speed in the browser.

Rebuild from repository root:

```sh
blender --background --python scripts/build-character.py
# Optional CPU-rendered studio preview:
blender --background --python scripts/build-character.py -- --render
```

Budget and inspection results are recorded in `inspection.json`. This is an original prototype character suitable for further art work; it is not claimed to match the finish of a commercial production character. The runtime embeds the GLB through Vite so the standalone browser HTML needs no asset server.
